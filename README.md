# My Favorite Series: Stranger Things
![Stranger Things Poster](https://upload.wikimedia.org/wikipedia/en/f/f7/Stranger_Things_season_4.jpg)

## Plot Summary
Stranger Things is a sci-fi horror series set in the 1980s about a group of kids who uncover supernatural mysteries in their small town.

**Main Characters:**
- Eleven
- Mike Wheeler
- Dustin Henderson
- Lucas Sinclair
- Will Byers
